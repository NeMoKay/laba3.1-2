## Архитектура ЛР1

- `include/avl_tree.hpp` — шаблонное АВЛ-дерево с поддержкой инварианта баланса $|\Delta h| \le 1$, обходами (ЛКП и др.), итератором и интерфейсом `ICollection`.
- `include/Set.hpp` — шаблонное множество, инкапсулирующее `AVLTree<T, bool>`.

## Сборка и запуск (Makefile)

- `make main1` — запуск исполняющего файла ЛР-1.
- `make main2` — запуск исполняющего файла ЛР-2.
- `make test` — запуск юнит-тестов.
- `make load_test` — нагрузочное тестирование в сравнении со `std::map` / `std::set` с выгрузкой в `benchmark.csv`.
- `make all_test` — запуск test и load_test.
- `make plot` — построение графиков производительности по `benchmark.csv` (`scripts/plot.py`).
